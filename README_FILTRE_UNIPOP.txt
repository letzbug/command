UniPop COMMAND – filtre de la source trainings.json

Uniquement les cours dont organisateur.code est UNIPOP (casse ignorée) sont importés lors du chargement JSON et de la synchronisation. Les autres sont ignorés, sans modification de la logique du calendrier.

IMPORTANT : pour éliminer les cours non-UniPop déjà présents dans le cache local, actualiser la source ou réimporter le JSON. Aucun nettoyage automatique des événements ou tâches locales.

Fichiers de déploiement: index.html ou dist-single/index.html; ils incluent la modification.
