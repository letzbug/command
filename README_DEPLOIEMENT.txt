UniPop COMMAND - version GitHub Pages autonome

1. Creez un depot GitHub (ex. unipop-command).
2. Deposez index.html et .nojekyll a la racine du depot (pas le ZIP).
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Ouvrez https://VOTRE-COMPTE.github.io/NOM-DU-DEPOT/

Cette version est autonome et fonctionne en stockage LOCAL par navigateur.
Supabase/Cloudflare non connectes : les donnees ne sont pas synchronisees entre appareils.
La source des cours JSON peut necessiter un proxy selon les regles CORS.
